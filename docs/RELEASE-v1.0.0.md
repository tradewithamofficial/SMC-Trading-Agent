# v1.0.0

Initial Windows x64 onedir release of Trade With AM — SMC Trading Agent.

- Six demonstration model boxes; all six models remain in the V1 analysis scope.
- 1D/4H/1H context with 15m/5m execution; up to three justified chart ideas.
- Direct model/MCP drawing and independently hideable SMC Intraday Setup groups.
- Read-only existing-setup entry checks in a copyable popup.
- Optional complete-response multipart Telegram notifications for successful setup
  analysis only; no summarization or automatic retry.
- Editable public prompts and local saved responses.

No automated order execution or automatic old-group deletion/replacement.
The operator approved the current transparent chart illustration and conversion
of the existing rose robot PNG to ICO without redesigning it. Working prompts,
CLI arguments, MCP integration, GUI and Telegram logic were preserved for packaging.

Windows users must install/configure TradingView Desktop, Node.js, TradingView MCP
and authenticated Codex CLI/model access separately. Python is bundled in the ZIP.
No credentials, local responses or session records belong in source/release assets.
